# NOVA

Неофициальный персональный лаунчер для NOVA RP на Windows 10/11 x64

[Скачать установщик NOVA](https://github.com/fastnightshadow-bit/nova-launcher-updates/releases/latest/download/NOVA-Discord.zip)

Распакуй архив целиком и открой `Install-NOVA.cmd`
При первой установке нужен интернет — скачивается около 160 МБ с официального GitHub Electron
После установки открывай NOVA через ярлык на рабочем столе

- New Era, Mirage и Horizon — выбор по нажатию на название сервера слева внизу
- Онлайн с официального источника NOVA
- С 21:00 до 07:00 — ночной город с луной и звёздами по времени компьютера
- Уведомление о новой версии и обновление в один клик с сохранением настроек

Для игры нужны установленные GTA V, RAGE Multiplayer и официальный лаунчер NOVA RP
Подключение выполняется через установленный официальный компонент NovaConnect
Эти программы не входят в архив

Если у тебя старая версия без автообновления, установи эту версию один раз
Дальше новые выпуски будут предлагаться внутри NOVA

`latest.json` и файлы `.nova` предназначены для автоматического обновления
Вручную их открывать не нужно
Лаунчер проверяет цифровую подпись и целостность пакета перед установкой

Этот проект не является официальным продуктом NOVA RP, Rockstar Games или RAGE Multiplayer
